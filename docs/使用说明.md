# 使用说明（中文）

羽毛球俱乐部排场工具：网页应用，支持多俱乐部、多场地，自动编排双打对阵、录入比分、更新积分、查询历史。界面默认中文，可在侧边栏切换 English。

## 安装与启动

```bash
./setup.sh      # 首次：创建虚拟环境并安装依赖
./startup.sh    # 启动（默认 http://localhost:8501）
```

## 首次使用

1. 打开页面后先**创建俱乐部**（名称不能与已有俱乐部重复）。
2. 侧边栏「俱乐部」下拉框可随时切换俱乐部；「新建俱乐部」展开框可添加新俱乐部。
3. 到「成员」页录入俱乐部成员：姓名必填、可设初始积分（默认 1000）。同俱乐部内姓名不可重复。

## 每晚流程（今晚页）

1. **勾选出席**：勾选今晚到场的成员。整晚都可以随时勾/取消，只有当前勾选的人参与排阵。正在场上打球的人自动从候选中排除。
2. **设置场地数量**：顶部可调 1–12 块场地，自动保存，下次打开记住。
3. **生成对阵**：点「为 N 个空闲场地生成对阵」，系统按以下优先级自动编排（人多时优先照顾休息最久的人；尽量双方实力接近；尽量换搭档、换对手）。
   - 每块场地需要 4 个空闲的人。人不够时只生成部分场地，其余显示「空闲」。
   - 「在场」一栏显示每人所在场地号（如 1、2），没排到的人显示「休息」。
4. **开赛**：确认某块场地的对阵后点「开赛」，该场比赛正式记录开始时间。
5. **换一组**：不满意当前建议可点「换一组」（人不够换不出时会提示）。
6. **录入比分**：比赛结束后在场地卡片输入 A、B 两队的最终比分（整数，0–30，必须分出胜负），点「提交比分」。比分提交后自动更新所有队员积分并写入历史，之后不可再改（录错了只能到历史页另作处理前请谨慎）。
7. **作废**：开赛后还没录比分的比赛可以作废，人会重新回到候选。

## 其他页面

- **成员**：查看/新增/删除成员（删除会同时清掉该人的出席记录；已打过的比赛保留在历史里）。
- **积分榜**：按当前积分排序，显示场次、胜负、胜率。
- **历史**：按时间范围（今天/近 7 天/近 30 天/自定义起止日期/全部）和球员筛选，查看每场的比分、时长、积分变化。

## 积分规则简述

团队总和 Elo（K=32）：以两队积分之和计算期望胜率，再乘以分差倍率（分差越大、双方越接近，倍率越高，限制在 1.0–2.0）。胜方每人加相同增量，负方每人减相同增量；积分在开赛时快照、提交比分时生效，保留 1 位小数、下限 0。完整公式与示例见 [积分规则](积分规则.md)。

## 数据

所有数据保存在本地 `data/` 目录（JSON 文件）：俱乐部列表、成员与积分、每日出席、比赛历史、场地设置。删除该目录会清空全部数据；请勿把 `data/` 提交到版本库。
